## 💻 在IDEA中运行（5分钟搞定）

### 第1步：打开项目
```
IDEA → File → Open → 选择 simple-servlet-form 文件夹
```

### 第2步：等待Maven
等待右下角Maven下载完成（第一次会慢一点）

### 第3步：配置Tomcat
1. 点击右上角 **Add Configuration**
2. 点击 `+` → **Tomcat Server** → **Local**
3. **Configure** → 选择Tomcat安装目录
4. 切换到 **Deployment** 标签
5. 点击 `+` → **Artifact** → 选择 `simple-servlet-form:war exploded`
6. **Application context** 改为 `/`
7. 点击 **OK**

### 第4步：运行
点击绿色运行按钮 ▶️

### 第5步：访问
浏览器自动打开 http://localhost:8080

**完成！**

## 🔍 代码解析

### 1️⃣ 表单页面 (index.html)

```html
<form action="submitForm" method="post">
    <input type="text" name="name" required>
    <input type="number" name="age" required>
    <input type="email" name="email" required>
    <button type="submit">提交</button>
</form>
```

**重点**：
- `action="submitForm"` - 提交到Servlet
- `method="post"` - 使用POST方式
- `name="xxx"` - 参数名称

---

### 2️⃣ Servlet处理器 (FormServlet.java)

```java
@WebServlet("/submitForm")  // ← URL映射
public class FormServlet extends HttpServlet {

    protected void doPost(HttpServletRequest request, HttpServletResponse response) {

        // 1. 获取参数
        String name = request.getParameter("name");
        String age = request.getParameter("age");

        // 2. 打印到控制台
        System.out.println("姓名: " + name);
        System.out.println("年龄: " + age);

        // 3. 传递给结果页面
        request.setAttribute("name", name);
        request.setAttribute("age", age);

        // 4. 跳转到结果页面
        request.getRequestDispatcher("/result.jsp").forward(request, response);
    }
}
```

**核心知识点**：
- `@WebServlet("/submitForm")` - 不用在web.xml配置！
- `request.getParameter()` - 获取表单数据
- `request.setAttribute()` - 传递数据
- `forward()` - 页面跳转

---

### 3️⃣ 结果页面 (result.jsp)

```jsp
<h1>提交成功！</h1>
<table>
    <tr>
        <td>姓名</td>
        <td><%= request.getAttribute("name") %></td>
    </tr>
    <tr>
        <td>年龄</td>
        <td><%= request.getAttribute("age") %></td>
    </tr>
</table>
```

**重点**：
- `<%= %>` - 输出Java表达式
- `request.getAttribute()` - 获取Servlet传递的数据

## 🐛 常见问题

### Q1: 控制台看不到打印？
**A**: 查看IDEA的Run窗口，或Tomcat的catalina.out日志

### Q2: 中文显示乱码？
**A**: 已经处理好了！代码里有：
```java
request.setCharacterEncoding("UTF-8");
```

### Q3: 点击提交后404？
**A**: 检查：
- Servlet的 `@WebServlet("/submitForm")`
- 表单的 `action="submitForm"`
- 两者必须一致！

### Q4: Maven依赖下载很慢？
**A**: 配置阿里云镜像，在Maven的settings.xml中添加：
```xml
<mirror>
  <id>aliyun</id>
  <url>https://maven.aliyun.com/repository/public</url>
  <mirrorOf>central</mirrorOf>
</mirror>
```
