# 如何在GitHub上找到项目

## 🔍 方法一：在GitHub网页上查看

### 第1步：打开你的GitHub仓库
```
https://github.com/wangsi001/Wangci_-
```

### 第2步：切换分支查看项目
1. 打开仓库后，页面左上角有一个**分支按钮**（显示 `main` 或其他分支名）
2. 点击这个分支下拉菜单
3. 在搜索框中输入：`claude/maven-tomcat-setup-guide`
4. 选择分支：`claude/maven-tomcat-setup-guide-011CUox8ErAXfQVMepRqg7cG`
5. 现在你就能看到 `maven-tomcat-webapp` 文件夹了！

### 或者直接访问这个链接：
```
https://github.com/wangsi001/Wangci_-/tree/claude/maven-tomcat-setup-guide-011CUox8ErAXfQVMepRqg7cG
```

## 💻 方法二：直接克隆到本地使用（最简单！）

### Windows用户：

#### 1. 安装Git（如果还没有）
下载：https://git-scm.com/download/win
双击安装，一路点"下一步"即可

#### 2. 打开命令行
- 按 `Win + R`
- 输入 `cmd`
- 按回车

#### 3. 克隆项目到本地
```bash
# 进入你想保存项目的位置（比如D盘）
D:
cd D:\

# 克隆整个仓库
git clone https://github.com/wangsi001/Wangci_-.git

# 进入项目目录
cd Wangci_-

# 切换到Maven项目的分支
git checkout claude/maven-tomcat-setup-guide-011CUox8ErAXfQVMepRqg7cG

# 查看项目文件
dir
```

现在项目就在：`D:\Wangci_-\maven-tomcat-webapp\`

#### 4. 用IDEA打开
- 打开 IntelliJ IDEA 2025
- File → Open
- 选择 `D:\Wangci_-\maven-tomcat-webapp` 文件夹
- 点击 OK

---

## 📱 方法三：用IDEA直接克隆（最推荐！）

### 1. 打开IDEA 2025

### 2. 克隆项目
- 点击欢迎界面的 **Get from VCS**
- 或者：File → New → Project from Version Control

### 3. 填写信息
```
URL: https://github.com/wangsi001/Wangci_-.git
Directory: 选择保存位置，比如 D:\Projects\Wangci_-
```

### 4. 点击 Clone
等待下载完成（可能需要几分钟）

### 5. 切换分支
- 克隆完成后，点击IDEA右下角的分支图标
- 在列表中找到：`origin/claude/maven-tomcat-setup-guide-011CUox8ErAXfQVMepRqg7cG`
- 点击它，选择 **Checkout**

### 6. 打开项目文件夹
- 在左侧项目树中找到 `maven-tomcat-webapp` 文件夹
- 右键点击这个文件夹
- 选择 **Open as Project** 或 **Add as Maven Project**

## ❓ 为什么在GitHub网页上看不到？

**答案**：因为这个项目在一个**独立的分支**上，不在默认的 `main` 分支。

- **main分支**：原有的Python项目（Wangci_学生成绩综合管理系统）
- **claude/maven...分支**：新的Maven Web项目

GitHub默认显示main分支，所以你需要手动切换分支才能看到Maven项目。

## 🚀 下一步：运行项目

下载到本地后，按照 `使用指南.md` 的步骤配置Tomcat并运行：

1. **下载Tomcat 10**：https://tomcat.apache.org/download-10.cgi
2. **在IDEA中配置Tomcat**（Add Configuration → Tomcat Server）
3. **添加Deployment**（maven-tomcat-webapp:war exploded）
4. **点击运行** ▶️
5. **访问**：http://localhost:8080
