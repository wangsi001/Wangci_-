## 🚀 运行项目

### 准备工作

1. **安装JDK 17**: https://www.oracle.com/java/technologies/downloads/#java17
2. **下载Tomcat 10**: https://tomcat.apache.org/download-10.cgi

### 在IDEA中运行

1. **打开项目**: `Github_wangsi/maven-tomcat-webapp`

2. **等待Maven下载依赖**（第一次会比较慢）

3. **配置Tomcat**:
   - 右上角 **Add Configuration**
   - 点 `+` → **Tomcat Server** → **Local**
   - **Configure** 选择Tomcat目录
   - **Deployment** 添加: `maven-tomcat-webapp:war exploded`
   - **Application context** 设为: `/`

4. **点击运行** ▶️

5. **访问**: http://localhost:8080
