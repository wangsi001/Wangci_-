## 🎯 方式一：使用IntelliJ IDEA 2025

### 第一步：克隆GitHub仓库到本地

#### 方法A：在IDEA中直接克隆（推荐）

1. **打开IDEA 2025**

2. **从GitHub克隆项目**

   - 或者：`File` → `New` → `Project from Version Control`

3. **填写信息**
   ```
   URL: https://github.com/wangsi001/Wangci_-.git
   Directory: 选择你想保存的本地目录，比如 D:\Projects\Wangci_-
   ```

4. **点击 Clone（克隆）**
   - IDEA会自动下载项目到本地

5. **切换到项目分支**
   - 克隆完成后，点击右下角的分支名称
   - 选择 `claude/maven-tomcat-setup-guide-011CUox8ErAXfQVMepRqg7cG`
   - 点击 `Checkout`（检出）

#### 方法B：使用命令行克隆

```bash

# 2. 进入你想保存项目的目录
```

---

### 第二步：在IDEA中配置项目

1. **打开Maven项目**
   - IDEA会自动识别这是Maven项目
   - 等待IDEA自动下载依赖（右下角会显示进度）
   - 如果没有自动导入，右键点击 `pom.xml` → `Maven` → `Reload Project`

2. **配置JDK**
   - `File` → `Project Structure` → `Project`
   - SDK选择 `Java 17`（如果没有，点击Add SDK下载安装）
   - Language Level选择 `17`

3. **配置Tomcat**

   **a. 下载Tomcat（如果还没有）**
   - 访问：https://tomcat.apache.org/download-10.cgi
   - 下载 `Tomcat 10.1.x` 的 `zip` 版本
   - 解压到某个目录，比如 `D:\Tomcat\apache-tomcat-10.1.20`

   **b. 在IDEA中配置Tomcat**
   - 点击右上角的 `Add Configuration`（添加配置）
   - 点击 `+` → `Tomcat Server` → `Local`

   **c. 配置Tomcat服务器**
   ```
   Name: Tomcat 10
   Application Server: 点击Configure，选择你的Tomcat目录（D:\Tomcat\apache-tomcat-10.1.20）
   ```

   **d. 配置部署**
   - 切换到 `Deployment` 标签
   - 点击 `+` → `Artifact` → 选择 `maven-tomcat-webapp:war exploded`
   - Application context设置为: `/` （或者留空）

   **e. 配置端口（可选）**
   - 在 `Server` 标签，可以修改端口（默认8080）
   - 勾选 `On 'Update' action: Update classes and resources`（热部署）
   - 勾选 `On frame deactivation: Update classes and resources`

4. **运行项目**
   - 点击右上角的绿色运行按钮 ▶️
   - 或按快捷键 `Shift + F10`
   - 等待Tomcat启动（控制台会显示启动日志）
   - 浏览器会自动打开 http://localhost:8080

## ❓ 常见问题

### 1. Maven依赖下载很慢
配置阿里云镜像，在Maven的 `settings.xml` 中添加：
```xml
<mirror>
  <id>aliyun</id>
  <mirrorOf>central</mirrorOf>
  <url>https://maven.aliyun.com/repository/public</url>
</mirror>
```

### 2. Tomcat端口被占用
- 修改端口：在IDEA的Tomcat配置中修改端口号
- 或者关闭占用8080端口的程序

### 3. 找不到Servlet类
- 确保Maven依赖已下载完成
- 右键项目 → Maven → Reload Project

### 4. 页面显示404
- 检查Tomcat是否正常启动
- 检查Context Path是否配置为 `/`
- 检查WAR包是否正确部署

### 5. Git Push被拒绝
- 先Pull拉取远程代码
- 解决冲突后再Push
